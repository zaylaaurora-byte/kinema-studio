## Character locks
- Demon host: adult-looking female demon with warm pale skin, messy long dark brown/black hair, curved black horns, pointed ears, amber/gold eyes, spade tail, oversized cream jumper. Mischievous, sarcastic, relaxed. Warm, low, subtly sleepy **neutral American** voice.
- Human: white minimalist rounded-head character with thick black linework and expressive eyes/eyebrows/mouth. Sweet, naive, confident, clumsy. **Completely silent: no spoken words.** Pilot outfit: removable explorer hat + backpack.
- Use the actual supplied images as visual references; do not redesign either character.
- Some exploratory sheets contain contradictory voice descriptors or alternate wardrobe. Written constraints above take precedence.
- Reference sheets are not transparent rig layers. Create and verify appropriate 2D layers/poses before treating them as animatable characters.
